# CleanStacks

A lightweight Valheim mod that hides maximum stack counts for a cleaner inventory interface.

## Features

- Hides max stack counts in the hotbar
- Hides max stack counts in player inventories
- Hides max stack counts in chests
- Hides max stack counts in supported modded inventories
- Does **not** change actual item stack sizes
- Extremely low performance impact (rewritten in 1.1.0)

## Requirements

- [BepInEx](https://thunderstore.io/c/valheim/p/denikson/BepInExPack_Valheim/)

## Installation

**Recommended:**  
Install with a mod manager (r2modman / Thunderstore Mod Manager).

**Manual:**  
Place `CleanStacks.dll` into:  
`BepInEx/plugins/CleanStacks/`

## Compatibility

Works with any inventory that uses standard Valheim UI components.  
Some heavily customized modded inventories may not be affected.
